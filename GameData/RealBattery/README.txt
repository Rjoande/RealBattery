RealBattery Recharged v3.4.3
=============================

A complete overhaul of the stock electric system in Kerbal Space Program,
originally designed by Blackliner. Batteries store energy (StoredCharge) and
supply power (ElectricCharge) up to their rated capacity, with realistic
discharge/recharge, chemistry-specific behavior, thermal effects, wear, and
tech-tree progression.

Full documentation, screenshots, and the changelog:
https://github.com/Rjoande/RealBattery

REQUIRED DEPENDENCIES
----------------------
- Module Manager
- B9PartSwitch
- Community Resource Pack

SUGGESTED / RECOMMENDED
-------------------------
- SystemHeat
- Community Tech Tree
- System Monitor (Dynamic Battery Storage)
- DangIt! Continued
- Bon Voyage
- Conformal Decals
- HarmonyKSP (only needed for the optional Bon Voyage fallback bridge)
- MFD Extended (https://github.com/Rjoande/MFD-Extension) - adds an in-IVA
  battery management display (BMS bay: EPS Summary, Battery Management, and
  Fleet Overview screens); RealBattery works identically without it.

INSTALLATION
-------------
1. Remove any previous RealBattery install.
2. Make sure this GameData/RealBattery folder is merged into your own
   GameData folder (do not nest it one level too deep).
3. Ensure the required dependencies above are installed.
4. (Optional) Install any of the Extras from the release package as desired.

Starting a new save is recommended to enjoy the full tech progression.
Installing mid-career is possible, but may affect in-flight vessels' power
balance.
